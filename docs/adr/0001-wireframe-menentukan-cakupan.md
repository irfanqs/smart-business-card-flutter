# Wireframe menentukan cakupan fitur aplikasi

Untuk proyek tugas kuliah ini, fitur aplikasi mengikuti wireframe dan kebutuhan pendukung yang dikonfirmasi pengguna, seperti layar login dan pengaturan kata sandi. Diagram aktivitas dan use case membantu menjelaskan alur, tetapi tidak menambah fitur dengan sendirinya; karena itu antarmuka admin untuk mengelola pengguna dan memantau sistem semula tidak dibuat. Label NFC dan verifikasi pada wireframe juga dihapus karena tidak ada fungsi NFC atau proses verifikasi dalam cakupan yang disepakati. Keputusan ini menjaga implementasi tetap sesuai rancangan yang akan dinilai dan menghindari klaim kemampuan yang tidak dibuat.

Cakupan admin kemudian diubah atas permintaan pengguna; lihat [ADR 0004](0004-dashboard-admin.md).
